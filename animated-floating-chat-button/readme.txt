== Description ==

**Animated Floating Chat Button** is a simple and effective plugin that lets users connect with you directly on WhatsApp from your website. It adds an **animated floating WhatsApp button** on your WordPress site.

== Installation ==

1. Download the plugin ZIP file.
2. Go to **WordPress Dashboard → Plugins → Add New**.
3. Click **Upload Plugin**, select the ZIP file, and install.
4. Activate the plugin.
5. Go to **WordPress Admin → Chat Button** to configure settings.

== Frequently Asked Questions ==

= Where do I find the settings? =
You will find a new **"Chat Button" menu item** in your WordPress admin panel.

= How do I change the WhatsApp number? =
Go to **WordPress Admin → Chat Button** and update the phone number field.

= Can I disable the floating button? =
Yes, go to **WordPress Admin → Chat Button** and toggle visibility off.

= Does this plugin store any user data? =
No, it does not collect or store any user information.

= Will this plugin slow down my website? =
No, it is lightweight and optimized for speed.

== External Services ==

This plugin uses the **WhatsApp API** to enable users to send messages directly via WhatsApp. Below are the details of the external service used:

### **WhatsApp API**
- **What it is**: The WhatsApp API is a service provided by WhatsApp (owned by Meta) that allows users to send messages via the WhatsApp platform.
- **What it is used for**: This plugin uses the WhatsApp API to generate a link that opens a chat with the configured WhatsApp number and pre-filled message.
- **What data is sent**: When a user clicks the floating button, the plugin sends the following data to WhatsApp:
  - The phone number configured in the plugin settings.
  - The default message configured in the plugin settings (if any).
- **When data is sent**: Data is sent only when the user clicks the floating button to initiate a chat.
- **Terms of Service**: [WhatsApp Terms of Service](https://www.whatsapp.com/legal/terms-of-service)
- **Privacy Policy**: [WhatsApp Privacy Policy](https://www.whatsapp.com/legal/privacy-policy)

== Privacy Policy ==

This plugin does not collect, store, or process any user data. It only generates a link to WhatsApp when the floating button is clicked, and no information is stored on the server or shared with third parties other than WhatsApp (as described in the External Services section).
